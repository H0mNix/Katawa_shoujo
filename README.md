## Abstract
This project was given by one of my teacher so we can learn AJAX and how to make dynamic pages.

This project was to make the first act of a visual novel named "Katawa Shoujo" in HTML, CSS, JavaScript and PHP using AJAX to communicate with the database to have data so we don't have to refresh the page.

## Functionnalities
In this game we can :
  - Create an account (the teacher told us to make a system that if the username and password doesn't exist we create the user in the database.
  - You can progress inside the story using the mouse or spacebar to see the text.
  - You can save your progression and then load.
  - You can make choice that change how the story will be.

## Bugs still present
